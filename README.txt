TAYLER CLINE COACHING — SIMPLE EDITABLE V1

You only need to edit ONE file: index.html

1. Right-click index.html
2. Choose Open with > Notepad
3. At the very top, find "✏️ EDIT YOUR WEBSITE HERE"
4. Edit the CONTENT section immediately below it.
5. Save.
6. Refresh the website in Chrome.

You do NOT need to open any .js file.

logo.jpg = your logo
styles.css = design; leave it alone unless you want design changes.
